Kenya Import Duty Rate Reference Guide

Updated April 2026 | EAC Common External Tariff (CET)

Import Duty Calculation Formula
CIF Value = Cost + Insurance + Freight (USD)
Import Duty = CIF Value × Duty Rate (%)
Excise Duty = (CIF + Import Duty) × Excise Rate (%)
IDF Fee = CIF Value × 2.25% (minimum USD 50)
VAT = (CIF + Import Duty + Excise Duty) × 16%

Additional Fees:

• VAT: 16% on (CIF + Duty + Excise)
• Railway Development Levy: 1.5% of CIF
