Kenya import costs can include customs duty, VAT, excise duty, IDF, RDL and other agency or port charges depending on the cargo.

## What affects the final amount

- HS code and customs valuation.
- Cargo description and regulatory controls.
- Vehicle CRSP, engine capacity and age.
- Inspection, storage and handling exposure.

Use the import duty calculator for an estimate, then confirm the file with a customs professional before making commercial decisions.
